# Import and Scope Assignment

## Objective
Practice Python imports and scope concepts by:

- Importing built-in Python modules
- Importing functions and variables from another file
- Creating and storing employee information
- Converting Python objects into JSON
- Writing JSON data to a file

## Files

- employee.py
  - Stores employee variables and details()

- jsongenerator.py
  - Creates dictionaries and handles JSON generation

- employee.json
  - Stores generated employee data

## Concepts Practiced

- import statements
- from ... import ...
- functions
- variable scope
- JSON handling
- reusable code organization
